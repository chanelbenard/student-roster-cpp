# Student Roster Management System

A C++ console application that manages student records using object-oriented programming principles.

## Overview

This project was created to organize and process student roster data. The application parses student information, stores records as objects, and provides functionality for managing and analyzing student data.

The program demonstrates core C++ concepts including object-oriented programming, classes, pointers, arrays, input validation, and data processing.

## Features

- Add student records to the roster
- Remove students by student ID
- Display all student information
- Filter students by degree program
- Validate student email addresses
- Calculate average course completion time
- Parse comma-separated student data
- Display an error when attempting to remove a student who does not exist

## Project Structure

- `student.h` – Defines the Student class and student attributes
- `student.cpp` – Implements Student class methods
- `roster.h` – Defines the Roster class and roster operations
- `roster.cpp` – Implements student management functionality
- `degree.h` – Defines the DegreeProgram enum
- `main.cpp` – Runs the application and demonstrates roster functionality

## Problem Solved

Managing student records manually can make it difficult to validate information, calculate course statistics, and organize students by degree program.

This application automates those tasks by converting raw student data into structured objects and providing functions to search, filter, validate, calculate, and remove records.
